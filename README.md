# حسين | مكافحة القوارض والحشرات

موقع عربي ثابت للتعريف بخدمات مكافحة القوارض والحشرات. يعمل مباشرةً دون إطار عمل أو خطوات بناء.

## النشر على GitHub Pages

1. ارفع ملفات المشروع إلى مستودع GitHub مع الحفاظ على مجلد `images`.
2. افتح **Settings → Pages** في المستودع.
3. ضمن **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع الذي يحتوي الملفات والمجلد الجذر (`/root`)، ثم اضغط **Save**.
5. بعد اكتمال النشر، سيظهر رابط الموقع في صفحة إعدادات Pages.

يجب أن يبقى `index.html` في جذر المستودع، وأن يبقى ملف الصورة ضمن `images` حتى تظهر صورة الصفحة.
